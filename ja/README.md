# AI開発マニュアル（日本語版）

AIと協力して、さまざまなソフトウェア開発プロジェクトを進めるための共通ルールとテンプレートです。

## ファイル構成

- `README.md`：このファイル。マニュアルの概要と使い方
- `AI_DEVELOPMENT_MANUAL.md`：共通指示、作業テンプレート、チェックリスト
- ルートの `.gitignore`：OS・エディタなどが作る不要ファイルを除外する設定

## 使い方

1. このリポジトリを共通マニュアルの保管場所として、各プロジェクトのリポジトリとは分けて管理します。
2. 新規・既存どちらのプロジェクトでも、[プロジェクト開始テンプレート](../templates/PROJECT_START_PROMPT.md)をAIに渡し、分かる範囲で情報を記入します。未確定の項目は空欄のままAIと相談できます。
3. [AI開発マニュアル](./AI_DEVELOPMENT_MANUAL.md)の共通ルールを使い、マニュアル全体を毎回貼る必要はありません。プロジェクト内の `AGENTS.md` などの指示や既存ルールも確認し、それらを尊重してください。
4. 既存プロジェクトでは、関連コード・設定とGitの状態を確認し、未コミット変更や未追跡ファイルを保持します。新規プロジェクトでは、まだコードがないことを確認し、目的・範囲・完了条件を整理します。
5. プロジェクト固有の決定事項は、そのプロジェクトの `README.md` や設計書に記録します。大きな作業の完了時や会話を中断するときは、「進捗・引き継ぎ記録テンプレート」を更新します。
6. GitHub Desktopに限らず、利用者が選んだGitクライアントとプロジェクトの既存ワークフローに従います。意味のある作業単位でコミットし、Pushは適切な確認後に行います。

## 運用ルール

- このリポジトリは、すべてのプロジェクトで使う共通ルールの保管場所です。
- アプリ本体のコードや秘密情報（APIキー、パスワード、トークンなど）は保存しません。
- マニュアルを改善した場合は、変更理由が分かるコミットメッセージを付けます。
- 新しいプロジェクトを始める際は、共通マニュアルを基準にしつつ、そのプロジェクトに合わないルールはAIと相談して調整します。
