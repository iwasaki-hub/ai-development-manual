# AI開発マニュアル（日本語版）

AIと協力して、さまざまなソフトウェア開発プロジェクトを進めるための共通ルールとテンプレートです。

## ファイル構成

- `README.md`：このファイル。マニュアルの概要と使い方
- `AI_DEVELOPMENT_MANUAL.md`：共通指示、作業テンプレート、チェックリスト
- `.gitignore`：OS・エディタなどが作る不要ファイルを除外する設定

## 使い方

1. このリポジトリをGitHubに保存し、プロジェクトごとのリポジトリとは分けて管理します。
2. 新しいプロジェクトを始めるときは、`AI_DEVELOPMENT_MANUAL.md` の「AIへの共通指示」と「プロジェクト概要テンプレート」を使います。
3. AIに渡す際は、マニュアル全体を毎回貼る必要はありません。作業内容に合うテンプレートと、今回必要な情報を共有してください。
4. プロジェクト固有の情報（技術構成、ディレクトリ構成、命名規則など）は、各プロジェクトの `README.md` や設計書に記録します。
5. 大きな作業の完了時や会話を中断するときは、「進捗・引き継ぎ記録テンプレート」を更新します。
6. GitHub Desktopを使い、意味のある作業単位でコミットします。

## 運用ルール

- このリポジトリは、すべてのプロジェクトで使う共通ルールの保管場所です。
- アプリ本体のコードや秘密情報（APIキー、パスワード、トークンなど）は保存しません。
- マニュアルを改善した場合は、変更理由が分かるコミットメッセージを付けます。
- 新しいプロジェクトを始める際は、共通マニュアルを基準にしつつ、そのプロジェクトに合わないルールはAIと相談して調整します。
